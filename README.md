# Image Inspector (Godot 4.4)

### Current functionality:
- file browser with drag and drop support (with a 'recents' section for easy access to recently opened files)
- zoom (with trackpad gestures support)
- different filtering based on image zoom (or based on user preferences)
- different color profiles (RGB, R, G, B, Inverted, Grayscale)
- color picker (kinda buggy rn)

### Supported formats:
- png
- jpg/jpeg
- webp
- svg
- bmp
- tga
